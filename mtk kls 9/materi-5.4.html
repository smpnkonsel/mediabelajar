01 — Menggambar Grafik

Menggambar Grafik Persamaan Garis

Karena garis lurus hanya butuh dua titik untuk ditentukan, menggambar grafiknya cukup dengan mencari dua (atau tiga, untuk memastikan) titik yang memenuhi persamaan, lalu menghubungkannya.

Langkah-langkah 1. Pilih beberapa nilai x sembarang (biasanya yang mudah dihitung, misalnya −1, 0, 1, 2).
2. Substitusikan setiap nilai x ke persamaan untuk mendapatkan nilai y yang bersesuaian.
3. Gambarkan pasangan titik (x, y) itu di bidang koordinat.
4. Hubungkan titik-titik tersebut dengan sebuah garis lurus, lalu perpanjang ke kedua arah.
Contoh — metode tabel nilai

Gambarlah grafik dari persamaan y = 2x − 1.

Tabel nilai untuk x = −1, 0, 1, 2
x−1012
y = 2x − 1−3−113
Hasil

Titik (−1,−3), (0,−1), (1,1), dan (2,3) ternyata segaris. Hubungkan keempatnya dengan penggaris menjadi satu garis lurus yang condong naik (karena m = 2 > 0).

Cara cepat: pakai dua titik potong sumbu Cara lain yang lebih singkat adalah langsung mencari titik potong dengan sumbu-X dan sumbu-Y — cukup dua titik itu saja untuk menggambar garis. Caranya dibahas di slide berikutnya!

02 — Titik Potong Sumbu

Titik Potong dengan Sumbu-X dan Sumbu-Y

Dua titik yang paling praktis untuk menggambar (atau membaca) sebuah garis adalah tempat garis itu memotong sumbu koordinat.

Titik potong sumbu-Y Terjadi saat x = 0. Substitusikan x = 0 ke persamaan untuk mendapatkan nilai y.

y = m(0) + c = c

Titik potong sumbu-X Terjadi saat y = 0. Substitusikan y = 0 ke persamaan lalu selesaikan untuk x.

0 = mx + c → x = −c/m

Contoh 1

Tentukan titik potong sumbu-X dan sumbu-Y dari garis y = 3x − 6.

Substitusi x = 0

y = 3(0) − 6 = −6 → titik potong sumbu-Y adalah (0, −6).

Substitusi y = 0

0 = 3x − 6 → 3x = 6 → x = 2 → titik potong sumbu-X adalah (2, 0).

Contoh 2 — bentuk ax + by + c = 0

Tentukan titik potong sumbu-X dan sumbu-Y dari garis 2x + 4y − 8 = 0.

Substitusi x = 0

2(0) + 4y − 8 = 0 → 4y = 8 → y = 2 → titik (0, 2).

Substitusi y = 0

2x + 4(0) − 8 = 0 → 2x = 8 → x = 4 → titik (4, 0).

Kasus khusus Jika m = 0 (garis horizontal, y = c dengan c ≠ 0), garis itu tidak pernah memotong sumbu-X. Sebaliknya, garis yang melalui titik asal (0,0) memiliki titik potong sumbu-X dan sumbu-Y yang sama, yaitu (0,0).

03 — Membaca Grafik

Membaca Informasi dari Grafik Garis Lurus

Dari sebuah grafik yang sudah digambar, kita bisa "membaca mundur" berbagai informasi: gradien, titik potong sumbu, arah kemiringan, hingga persamaan lengkapnya.

Apa saja yang bisa dibaca • Arah: naik (m > 0), turun (m < 0), atau mendatar (m = 0)?
• Titik potong sumbu-Y: lihat di mana garis menyentuh sumbu-Y → itu nilai c.
• Gradien: pilih dua titik jelas pada garis, hitung Δy/Δx.
• Persamaan lengkap: gabungkan m dan c menjadi y = mx + c.
Contoh

Sebuah grafik memotong sumbu-Y di (0, 5) dan memotong sumbu-X di (2, 0). Tentukan persamaan garis tersebut.

Baca c dari titik potong sumbu-Y

Garis memotong sumbu-Y di (0,5), jadi c = 5.

Hitung m dari dua titik potong

m = (0 − 5)/(2 − 0) = −5/2 = −2,5. Jadi y = −2,5x + 5.

Soal 2

Tentukan titik potong sumbu-X dan sumbu-Y dari garis y = −2x + 8.

Sumbu-Y (x=0): (0, 8). Sumbu-X (y=0): 0 = −2x+8 → x = 4 → (4, 0).

Soal 3

Tentukan titik potong sumbu-X dan sumbu-Y dari garis 3x − y + 9 = 0.

Sumbu-Y (x=0): −y+9=0 → y=9 → (0,9). Sumbu-X (y=0): 3x+9=0 → x=−3 → (−3, 0).

Soal 4

Sebuah grafik garis lurus memotong sumbu-Y di (0, −3) dan memotong sumbu-X di (6, 0). Berapa gradien garis tersebut?

m = (0 − (−3)) / (6 − 0) = 3/6 = 0,5.

05 — Ringkasan

Rangkuman Grafik Persamaan Garis Lurus

  • Menggambar grafik: pilih beberapa nilai x, hitung y-nya lewat persamaan, plot titik-titik itu, lalu hubungkan menjadi garis lurus.
  • Titik potong sumbu-Y didapat saat x = 0 (hasilnya y = c). Titik potong sumbu-X didapat saat y = 0 (hasilnya x = −c/m).
  • Dua titik potong sumbu adalah cara tercepat untuk menggambar sebuah garis, karena garis lurus hanya butuh dua titik.
  • Membaca grafik: arah garis (naik/turun/mendatar), titik potong sumbu-Y (=c), gradien dari dua titik jelas, lalu gabungkan menjadi y = mx + c.
