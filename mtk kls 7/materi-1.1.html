📖 Konsep Dasar

Apa itu Bilangan Bulat?

Bilangan bulat adalah himpunan bilangan yang terdiri dari bilangan negatif, nol, dan bilangan positif — tanpa bentuk pecahan atau desimal. Ditulis sebagai:

B = { ..., -3, -2, -1, 0, 1, 2, 3, ... }

➕ Bulat Positif
Contoh: ketinggian Gunung Rinjani +3.676 m di atas laut.
⚪ Nol
Contoh: permukaan laut sebagai titik acuan ketinggian 0 m.
➖ Bulat Negatif
Contoh: suhu freezer −18°C, di bawah titik nol.
