01 — Ikhtisar

Lima Kegiatan Pengolahan Data

Data dalam tabel bukan cuma disimpan, tapi juga perlu diolah agar tetap berguna. Berikut lima kegiatan utamanya — klik tiap kartu untuk penjelasan singkat, lalu coba langsung di slide-slide berikutnya!

02 — Memasukkan Data (Input)

Coba Tambahkan Data Buku Baru!

Mengisi data baru ke dalam tabel disebut input. Isi formulir di bawah ini, lalu klik "Tambah Data" — datamu akan langsung muncul di tabel, dan juga akan terbawa ke slide-slide berikutnya!

03 — Mengubah Data (Update)

Coba Ubah Salah Satu Data!

Kadang data perlu diperbarui, misalnya stok buku berkurang atau ada salah ketik. Klik tombol ✏️ Edit pada salah satu baris, ubah isinya, lalu klik 💾 Simpan.

💡 Mengubah data (update) penting agar informasi dalam tabel selalu akurat dan terkini.
04 — Mengurutkan Data (Sort)

Coba Urutkan dengan Klik Judul Kolom!

Klik judul kolom (Judul Buku, Penulis, Kategori, atau Stok) untuk mengurutkan tabel. Klik sekali untuk menaik (ascending ▲), klik lagi untuk menurun (descending ▼).

05 — Menyaring Data (Filter)

Coba Saring Data Sesuai Kriteria!

Menyaring (filter) berarti menampilkan hanya data yang sesuai kriteria tertentu, tanpa menghapus data lainnya. Coba atur kriteria berikut.

Mengelola Data Secara Menyeluruh

Mengelola data mencakup semua kegiatan sebelumnya, ditambah menghapus data yang tidak diperlukan lagi, menjaga data tetap valid, dan mengamankannya. Coba hapus salah satu data di bawah ini.
