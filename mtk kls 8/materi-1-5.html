Materi 1

Konsep Bilangan Berpangkat (Eksponen)

Definisi Eksponen

Perkalian berulang dari suatu bilangan yang sama. Jika $a$ adalah bilangan real dan $n$ adalah bilangan bulat positif:

aⁿ = a × a × a × ... × a
(sebanyak n faktor)

Contoh Interaktif (Klik Tombol)

2⁴ = 2 × 2 × 2 × 2 = 16
Materi 2

Sifat-Sifat Operasi Perpangkatan

Klik kartu untuk melihat contoh perhitungan!

Perkalian: aᵐ × aⁿ = aᵐ⁺ⁿ
Contoh: 2³ × 2² = 2³⁺² = 2⁵ = 32
Pembagian: aᵐ ÷ aⁿ = aᵐ⁻ⁿ
Contoh: 5⁶ ÷ 5⁴ = 5⁶⁻⁴ = 5² = 25
Pemangkatan: (aᵐ)ⁿ = aᵐˣⁿ
Contoh: (3²)³ = 3²ˣ³ = 3⁶ = 729
Pangkat Nol: a⁰ = 1 (a ≠ 0)
Contoh: 100⁰ = 1, (xy)⁰ = 1
Materi 3

Merasionalkan Penyebut Bentuk Akar

1. Bentuk a / √b

Kalikan pembilang dan penyebut dengan √b.

(a / √b) × (√b / √b) = (a√b) / b

2. Bentuk Sekawan: c / (a + √b)

Kalikan dengan bentuk sekawan (a - √b).

c/(a + √b) × (a - √b)/(a - √b) = c(a - √b) / (a² - b)

Simulasi Langkah Kerja: Rasionalkan 6 / √3

Soal: 6 / √3 → (6 / √3) × (√3 / √3) → 6√3 / 3 Hasil: 2√3
Materi 4 — Penerapan

Latihan Soal: Olimpiade & HOTS

Peserta didik menerapkan konsep bilangan berpangkat dan bentuk akar untuk menyelesaikan masalah tingkat tinggi. Klik soal untuk melihat pembahasan.

No. 1. Tentukan nilai n jika 2ⁿ⁺¹ + 2ⁿ = 96.
2ⁿ(2 + 1) = 96 → 2ⁿ × 3 = 96 → 2ⁿ = 32 = 2⁵ → n = 5
No. 2. Sederhanakan: √50 + √18 − √8.
5√2 + 3√2 − 2√2 = 6√2
No. 3. Jika x = 2 + √3, tentukan nilai x + 1/x.
1/x = (2−√3)/((2+√3)(2−√3)) = (2−√3)/1 = 2−√3
x + 1/x = (2+√3) + (2−√3) = 4
No. 4. Tentukan hasil dari (3¹⁰⁰ + 3¹⁰⁰ + 3¹⁰⁰) ÷ 3⁹⁹.
3 × 3¹⁰⁰ ÷ 3⁹⁹ = 3¹⁰¹ ÷ 3⁹⁹ = 3² = 9
No. 5. Jika 3^(2x−1) = 27^(x−2), tentukan nilai x.
27 = 3³ → 3^(2x−1) = 3^(3x−6) → 2x−1 = 3x−6 → x = 5
No. 1. Sebuah sampel bakteri membelah menjadi dua setiap 20 menit. Jika mula-mula ada 50 bakteri, berapa banyak bakteri setelah 2 jam?
n = 120 ÷ 20 = 6 kali. N = 50 × 2⁶ = 50 × 64 = 3.200 bakteri
No. 2. Luas sebuah persegi adalah (2 + √3) cm². Tentukan panjang sisi persegi dalam bentuk paling sederhana.
Sisi = √(2+√3). Bentuk ini dapat ditulis sebagai (√6+√2)/2, karena ((√6+√2)/2)² = (8+4√3)/4 = 2+√3.
Jadi sisi = (√6 + √2) / 2 cm
No. 3. Suatu zat radioaktif meluruh menjadi setengahnya setiap 10 tahun. Jika massa awal 800 gram, berapa massa zat yang tersisa setelah 40 tahun?
n = 40 ÷ 10 = 4. Massa = 800 × (1/2)⁴ = 800 ÷ 16 = 50 gram
No. 4. Sebuah segitiga siku-siku memiliki panjang kedua sisi siku-siku √12 cm dan √24 cm. Tentukan panjang sisi miringnya.
c² = (√12)² + (√24)² = 12 + 24 = 36 → c = √36 = 6 cm
No. 5. Sebuah kotak kubus memiliki volume 5⁶ cm³. Kotak diperbesar sehingga volumenya menjadi 5⁹ cm³. Berapa kali lipat panjang rusuk kubus bertambah?
Rasio volume = 5⁹ ÷ 5⁶ = 5³ = 125. Karena V = r³, rasio rusuk = ∛125 = 5 kali lipat
