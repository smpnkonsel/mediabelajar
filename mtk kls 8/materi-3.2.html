01 · Dasar-dasar

Apa itu PLSV?

Persamaan Linear Satu Variabel (PLSV) adalah kalimat matematika terbuka yang memuat tanda "=" dan hanya memiliki satu variabel berpangkat satu. Klik setiap bagian rumus di bawah untuk melihat penjelasannya.

Bentuk umum PLSV a x + b = c   (dengan a ≠ 0)
a
Koefisien
Angka yang menempel dan mengalikan variabel x. Tidak boleh bernilai 0, karena jika a = 0 maka x akan hilang dari persamaan.
x
Variabel
Simbol yang mewakili nilai yang belum diketahui dan akan kita cari. Bisa juga ditulis dengan huruf lain seperti y atau n.
b
Konstanta
Bilangan tetap yang berdiri sendiri di ruas kiri, tidak menempel pada variabel x.
c
Ruas kanan
Nilai konstanta di seberang tanda "=". Tujuan penyelesaian PLSV adalah membuat x sendirian di satu ruas, sehingga terlihat nilainya.
Contoh PLSV
2x + 5 = 17x − 4 = 96x = 30x/3 = 8
02 · Konsep Kunci

03 · Empat Operasi Dasar
+

Operasi Penjumlahan

Digunakan saat variabel x dikurangi suatu bilangan.

Jika  x − b = c , maka kedua ruas ditambah b:  x − b + b = c + b  →  x = c + b
03 · Empat Operasi Dasar
−

Operasi Pengurangan

Digunakan saat variabel x ditambah suatu bilangan.

Jika  x + b = c , maka kedua ruas dikurangi b:  x + b − b = c − b  →  x = c − b
03 · Empat Operasi Dasar
×

Operasi Perkalian

Digunakan saat variabel x dibagi suatu bilangan (berbentuk pecahan).

Jika  x ÷ b = c , maka kedua ruas dikalikan b:  x ÷ b × b = c × b  →  x = c × b
03 · Empat Operasi Dasar
÷

Operasi Pembagian

Digunakan saat variabel x dikalikan suatu bilangan (memiliki koefisien).

Jika  a x = c , maka kedua ruas dibagi a:  a x ÷ a = c ÷ a  →  x = c ÷ a
04 · Level Lanjutan

Menggabungkan Beberapa Operasi

Banyak soal PLSV butuh lebih dari satu operasi. Urutan yang biasa dipakai: selesaikan penjumlahan/pengurangan dulu, baru perkalian/pembagian. Ikuti langkah-langkahnya.

05 · Penerapan

Penerapan PLSV dalam Kehidupan Sehari-hari

PLSV sering dipakai untuk memecahkan masalah nyata: umur, harga barang, hingga keliling bangun datar. Kuncinya: ubah dulu cerita menjadi persamaan, baru selesaikan.

08 · Rangkuman

Rangkuman Materi

Empat aturan dasar untuk menyelesaikan PLSV — ingat prinsip utamanya: lakukan operasi yang sama pada kedua ruas.

OperasiKapan digunakanAturan
➕ Penjumlahan Saat bentuknya x − b = c Tambah b di kedua ruas → x = c + b
➖ Pengurangan Saat bentuknya x + b = c Kurangi b di kedua ruas → x = c − b
✖️ Perkalian Saat bentuknya x ÷ b = c Kali b di kedua ruas → x = c × b
➗ Pembagian Saat bentuknya a·x = c Bagi a di kedua ruas → x = c ÷ a
