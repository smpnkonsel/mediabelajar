BAB 4 • RELASI DAN FUNGSI

Penyajian Fungsi

Mari belajar bagaimana satu fungsi dapat disajikan dengan diagram panah, pasangan berurutan, tabel, dan grafik—serta melihat hubungan di antara keempatnya.

Tip: gunakan tombol ← dan → pada keyboard untuk berpindah slide.

Apersepsi

Bayangkan mesin fungsi

Suatu mesin menerima input, melakukan aturan tertentu, lalu menghasilkan output.

input → aturan fungsi → output

Contoh: aturan f(x) = 2x + 1. Jika input 3, outputnya?

f(3) = 2(3) + 1 = 7. Jadi 3 dipetakan ke 7.

Konsep Dasar

Apa itu fungsi?

Definisi sederhana

Fungsi adalah relasi yang memasangkan setiap anggota domain dengan tepat satu anggota kodomain.

Kunci: setiap input harus mempunyai tepat satu output.

Istilah penting

  • Domain = himpunan input.
  • Kodomain = himpunan tujuan.
  • Range = anggota kodomain yang benar-benar mendapat pasangan.

Notasi

f : A → B    atau    y = f(x)

Artinya fungsi f memetakan setiap anggota A ke tepat satu anggota B.

Aktivitas

Bangun diagram panah

Gunakan aturan f(x)=x+2 dengan domain {1, 2, 3}. Pilih output yang benar untuk setiap input.

Penyajian 2

Pasangan berurutan

Setiap panah pada diagram dapat ditulis sebagai pasangan (x, y).

Dari diagram ke pasangan

(1, 3), (2, 5), (3, 7)

Angka pertama adalah input x; angka kedua adalah output y.

Ingat urutannya

(x, y) ≠ (y, x)

Pasangan (2, 5) berarti 2 dipetakan ke 5.

Hubungan dengan fungsi

Jika f(2)=5, pasangan berurutannya adalah (2,5).

Penyajian 4

Grafik fungsi

Pasangan berurutan (x,y) dapat digambarkan sebagai titik pada bidang koordinat.

Cara membuat grafik

LANGKAH 1Tentukan nilai x.
LANGKAH 2Hitung y=f(x).
LANGKAH 3Buat pasangan (x,y).
LANGKAH 4Plot titik dan amati polanya.
Eksplorasi Grafik

Geser input, lihat output

Untuk fungsi f(x)=2x+1, geser nilai x. Titik pada grafik dan nilai y berubah otomatis.

f(x) = 2x + 1 = 5

Pasangan berurutan: (2, 5)

Hubungan Antarpenyajian

Satu fungsi, empat wajah

Keempat penyajian berbeda bentuk, tetapi dapat memuat informasi fungsi yang sama.

DIAGRAM PANAH

Menunjukkan arah pemetaan input → output.

PASANGAN BERURUTAN

Menuliskan setiap pemetaan sebagai (x,y).

TABEL

Menata nilai x dan y dalam baris/kolom.

GRAFIK

Menempatkan pasangan (x,y) sebagai titik pada bidang koordinat.

Contoh yang sama: f(x)=2x+1 → (1,3), (2,5), (3,7) → tabel → titik-titik grafik.
Contoh Terpandu

Dari aturan ke empat penyajian

Misalkan f(x)=x+3 dengan domain {0,1,2,3}.

1 • HITUNGf(0)=3, f(1)=4, f(2)=5, f(3)=6.
2 • PASANGAN(0,3), (1,4), (2,5), (3,6).
3 • TABELMasukkan x dan f(x) pada dua kolom.
4 • GRAFIKPlot keempat pasangan sebagai titik.
