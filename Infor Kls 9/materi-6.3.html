Translasi Algoritma
Visual ke Tekstual

Mengubah blok atau langkah pemrograman visual menjadi instruksi dalam bahasa pemrograman tekstual, dengan tetap mempertahankan urutan, logika, kondisi, dan hasil algoritmanya.

Pemrograman Visual Algoritma Kode Tekstual Interaktif
APERSEPSI

Kalau bloknya hilang, apakah logikanya ikut hilang?

Bayangkan sebuah program visual memiliki blok: “ketika mulai → minta nama → tampilkan sapaan”. Bisakah kita menuliskannya kembali sebagai kode?

🧱

Blok

Program visual menyusun instruksi seperti kepingan puzzle. Bentuk blok membantu kita melihat alur dengan cepat.

🧠

Logika

Di balik bentuk blok terdapat algoritma: urutan langkah, data, kondisi, pengulangan, dan keluaran.

⌨️

Kode

Program tekstual menuliskan logika yang sama menggunakan aturan sintaks bahasa tertentu.

Ide utama: yang diterjemahkan bukan sekadar “bentuk blok”, tetapi makna instruksi dan alur algoritmanya.
TUJUAN PEMBELAJARAN

Setelah belajar, kamu mampu...

01

Mengenali struktur

Mengidentifikasi fungsi blok atau langkah pada algoritma visual: input, proses, keputusan, perulangan, dan output.

02

Memetakan konsep

Menentukan padanan konsep visual ke struktur dasar bahasa pemrograman tekstual.

03

Menjaga logika

Mempertahankan urutan dan perilaku algoritma ketika ditulis menjadi kode.

04

Menguji hasil

Memeriksa kode hasil translasi dengan menjalankan contoh sederhana dan menemukan kesalahan logika atau sintaks.

PERTANYAAN PEMANTIK

Apa yang sebenarnya berubah?

🧱

Visual

Blok, konektor, ikon, dan susunan grafis.

→
💻

Tekstual

Kata kunci, variabel, operator, tanda baca, dan struktur kode.

Yang tetap: tujuan program, data yang dipakai, urutan proses, kondisi keputusan, pengulangan, dan keluaran.
💡 Coba pikirkan:

Jika sebuah blok berkata “ulangi 5 kali”, bagian mana yang harus tetap muncul ketika algoritma diterjemahkan ke bahasa tekstual?

Jumlah pengulangan 5 kali dan isi tindakan yang diulang harus tetap dipertahankan. Bentuk penulisannya dapat berubah sesuai bahasa pemrograman.
KONSEP DASAR

Algoritma adalah “rencana kerja” program

Sebelum menerjemahkan, kita harus mampu membaca algoritmanya terlebih dahulu.

1️⃣

Input

Data yang masuk, misalnya nama, nilai, angka, atau pilihan pengguna.

⚙️

Proses

Pengolahan data seperti perhitungan, pemberian nilai variabel, atau manipulasi teks.

🔀

Keputusan

Program memilih tindakan berdasarkan kondisi benar atau salah.

🔁

Perulangan

Instruksi dijalankan berulang berdasarkan jumlah atau kondisi tertentu.

📤

Output

Informasi yang dihasilkan dan ditampilkan kepada pengguna.

➡️

Urutan

Instruksi dilaksanakan dari langkah yang satu menuju langkah berikutnya.

MEMBACA BLOK

Kenali fungsi setiap blok

Contoh algoritma visual sederhana untuk menyapa pengguna:

▶️ Ketika program dimulai
↓
⌨️ Minta nama pengguna
↓
🧮 Simpan nama ke variabel nama
↓
💬 Tampilkan “Halo, ” + nama

Urutan

Mulai → input → simpan data → tampilkan hasil.

Data

Variabel nama menyimpan informasi yang diberikan pengguna.

PADANAN KONSEP

Blok visual ↔ struktur tekstual

Konsep visualMakna algoritmikContoh bentuk tekstual (JavaScript)
Blok inputMenerima data dari penggunaprompt("Masukkan nama:")
Blok variabelMenyimpan datalet nama = ...;
Blok prosesMengolah datalet hasil = a + b;
Blok kondisiMemilih berdasarkan syaratif (nilai >= 75) { ... }
Blok ulangMengulang instruksifor (let i=0; i<5; i++) { ... }
Blok outputMenampilkan hasilconsole.log(hasil);

Catatan: padanan sintaks dapat berbeda pada Python, JavaScript, C++, Java, atau bahasa lainnya. Algoritmanya dapat sama meskipun penulisannya berbeda.

LANGKAH TRANSLASI

Jangan langsung mengetik kode

Gunakan proses bertahap agar logika tidak berubah.

1

Baca tujuan algoritma

Tentukan apa yang harus dilakukan program dari awal sampai akhir.

2

Identifikasi input dan output

Catat data yang masuk dan hasil yang harus keluar.

3

Kelompokkan proses

Pisahkan perhitungan, penyimpanan variabel, kondisi, dan perulangan.

4

Pilih struktur tekstual

Gunakan sintaks bahasa yang dipilih untuk mewakili konsep algoritma.

5

Periksa urutan

Pastikan kode berjalan dengan alur yang sama seperti algoritma visual.

6

Uji dan perbaiki

Gunakan data uji, amati hasil, lalu perbaiki kesalahan sintaks atau logika.

CONTOH 1 • URUTAN

Dari blok sapaan menjadi JavaScript

🧱 Algoritma visual
▶️ Mulai
↓
⌨️ Masukkan nama
↓
💬 Tampilkan “Halo, nama!”
⌨️ Translasi tekstual
JavaScript
const nama = prompt("Masukkan nama:");
console.log("Halo, " + nama + "!");
🔎 Perhatikan:

prompt() menggantikan aksi meminta input, variabel nama menyimpan input, sedangkan console.log() menghasilkan output.

CONTOH 2 • KONDISI

Blok “jika” diterjemahkan menjadi if

Misalkan algoritma visual menentukan kelulusan berdasarkan nilai minimal 75.

VISUAL
⌨️ Masukkan nilai
↓
🔀 Jika nilai ≥ 75
↓
📤 Tampilkan “Lulus”

Jika kondisi tidak terpenuhi, algoritma dapat memiliki cabang lain: “Tidak lulus”.

TEKSTUAL
JavaScript
const nilai = Number(prompt("Nilai:"));

if (nilai >= 75) {
  console.log("Lulus");
} else {
  console.log("Belum lulus");
}
Kunci translasi: bentuk berlian/blok keputusan berubah menjadi ekspresi kondisi if (...), sedangkan cabangnya menjadi blok kode.

CONTOH 4 • PERHITUNGAN

Translasi proses matematika

Algoritma: masukkan panjang dan lebar → hitung luas → tampilkan hasil.

A

Input

Ambil panjang dan lebar.

B

Proses

Gunakan rumus luas = panjang × lebar.

C

Output

Tampilkan nilai luas.

JavaScript
const panjang = 8;
const lebar = 5;
const luas = panjang * lebar;

console.log(luas); // 40
🧠 Cek logika:

Jika panjang menjadi 10 dan lebar 4, berapakah hasil yang seharusnya muncul?

AKTIVITAS 2 • MATCHING

Pasangkan konsep visual dengan kode

Pilih padanan yang benar untuk setiap konsep.

1. Simpan data ke variabel
2. Keputusan berdasarkan kondisi
3. Mengulang 5 kali
4. Menampilkan hasil
KESALAHAN UMUM

Translasi bukan sekadar mengganti simbol

KESALAHAN

Mengubah urutan

Output ditulis sebelum proses selesai sehingga hasil belum tersedia.

PERBAIKAN

Pertahankan alur

Ikuti urutan algoritma: input → proses → keputusan/perulangan jika ada → output.

KESALAHAN

Salah tipe data

Input angka dari teks langsung dijumlahkan sebagai string, misalnya “7” + “3” menjadi “73”.

PERBAIKAN

Konversi data

Pada JavaScript, gunakan Number() bila input harus diproses sebagai angka.

KESALAHAN

Kondisi berubah makna

Operator >, >=, atau == ditulis tidak sesuai algoritma.

PERBAIKAN

Uji kasus batas

Jika batasnya 75, coba nilai 74, 75, dan 76 untuk memastikan kondisi benar.
