Essay Soal 1 - Resolusi vs Ukuran File

Perbedaan: Resolusi adalah jumlah piksel (lebar × tinggi), sedangkan ukuran file adalah besarnya data yang disimpan dalam byte/MB. Contoh: Gambar 1920×1080 dengan 24-bit = ~6MB, tetapi gambar 100×100 dengan 24-bit = ~30KB. Resolusi sama tidak berarti ukuran file sama jika bit warna berbeda.

Essay Soal 2 - Proses Sensor Kamera

Proses: 1) Cahaya dari objek memasuki lensa, 2) Sensor (CCD/CMOS) menangkap cahaya dan mengubahnya menjadi muatan elektrik, 3) Charge-Coupled Device (CCD) atau CMOS membaca muatan setiap piksel, 4) Analog-to-Digital Converter (ADC) mengubah sinyal analog menjadi digital, 5) Processor menggabungkan data RGB dan mengkompresi data, 6) File gambar disimpan dalam format tertentu.

Essay Soal 3 - Keuntungan Layer dan Blend Mode

Keuntungan: 1) Non-destructive editing - tidak menghapus data asli, 2) Fleksibilitas - dapat menyesuaikan opacity dan blend mode kapan saja, 3) Kontrol presisi - mengedit bagian tertentu tanpa mempengaruhi layer lain, 4) Hasil natural - blend mode memberikan transisi warna yang halus dan realistis, 5) Kemudahan revisi - dapat menghapus layer dan mencoba opsi lain.

Essay Soal 4 - PNG vs JPEG untuk Desain

Alasan PNG lebih cocok: 1) PNG lossless - tidak kehilangan detail, 2) Mendukung transparansi alpha channel - penting untuk desain berlapis, 3) Tidak ada kompres lossy yang mengurangi kualitas, 4) Format JPEG lossy akan meninggalkan artefak kompresi yang terlihat pada garis tajam, 5) PNG ideal untuk grafis, logo, desain yang memerlukan presisi tinggi.

Essay Soal 5 - Langkah Membuat Poster

Langkah: 1) Perencanaan - tentukan tema, ukuran, dan konsep visual, 2) Siapkan aset - kumpulkan gambar, font, elemen desain, 3) Buat kanvas baru dengan ukuran yang tepat, 4) Import dan arrange elemen (gambar, teks) menggunakan layer, 5) Lakukan penyuntingan - crop, resize, adjust warna & kontras, 6) Terapkan efek/filter jika diperlukan, 7) Merge layer atau export dengan layer, 8) Simpan hasil dalam format PNG (desain) dan JPG (publikasi).
