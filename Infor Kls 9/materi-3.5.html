Memilih Format saat Menyimpan

SOAL

Rian membuat logo untuk klub robotik sekolahnya. Logo tersebut nantinya akan ditempel di berbagai warna latar belakang (poster, baju, banner), sehingga perlu memiliki latar transparan. Format apa yang sebaiknya dipilih Rian saat menyimpan (export) logo tersebut?

1Logo membutuhkan latar belakang transparan agar bisa menyatu dengan warna apa pun di belakangnya.
2Format PNG mendukung transparansi, sedangkan JPG tidak.
Jawaban: PNG — karena mendukung transparansi latar belakang.
Contoh Soal 2 dari 4

Membagikan Hasil Edit

SOAL

Sinta mengedit foto liburannya memakai sebuah aplikasi editor, dan hasilnya masih tersimpan dalam format kerja aplikasi tersebut (belum diekspor). Apa yang perlu dilakukan Sinta agar fotonya bisa dibuka dan dilihat di HP temannya yang tidak memakai aplikasi yang sama?

1Format kerja aplikasi biasanya hanya bisa dibuka oleh aplikasi itu sendiri.
2Sinta perlu memakai menu "Save As" atau "Export" untuk mengubahnya ke format gambar umum.
Jawaban: Ekspor (Save As / Export) foto ke format umum seperti JPG atau PNG.
Contoh Soal 3 dari 4

Urutan Langkah Menyimpan

SOAL — PILIHAN GANDA

Manakah urutan langkah menyimpan hasil edit gambar yang paling tepat?

A. Beri nama file → Klik File → Pilih format → Klik Save
B. Klik File → Pilih Save As/Export → Pilih format → Beri nama & folder → Klik Save
C. Pilih format → Klik Save → Klik File → Beri nama file
D. Klik Save → Klik File → Pilih format → Beri nama file
1Langkah selalu dimulai dari membuka menu File terlebih dahulu.
2Kemudian pilih "Save As" atau "Export", lalu tentukan format file (PNG/JPG).
3Setelah itu beri nama file dan pilih folder, baru terakhir klik Save/Export.
Jawaban: B

Etika dalam Berkarya Digital

SOAL — STUDI KASUS

Andi mengambil gambar dari internet untuk poster tugas sekolahnya, lalu langsung menggunakannya tanpa mencantumkan sumber atau memeriksa izin penggunaannya. Hal penting apa yang diabaikan Andi?

1Gambar buatan orang lain di internet umumnya tetap memiliki hak cipta / lisensi tertentu.
2Menggunakannya tanpa izin atau tanpa mencantumkan sumber melanggar etika dan bisa melanggar hukum hak cipta.
Jawaban: Andi mengabaikan hak cipta — sebaiknya ia mencantumkan sumber, meminta izin, atau memakai gambar berlisensi bebas/karya sendiri.
