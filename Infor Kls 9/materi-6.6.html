Bab 6PemrogramanVisual → Tekstual

Belajar mengubah ide atau alur pemrograman visual menjadi program berbasis teks, lalu menggunakannya untuk memecahkan masalah sederhana secara sistematis.

Misi belajar: pahami masalah → susun algoritma → terjemahkan blok/konsep → tulis kode → uji → perbaiki.
01 • Apersepsi

Dari blok ke baris kode

Pernah melihat program dibuat dengan menyusun blok seperti puzzle? Pemrograman tekstual menggunakan gagasan yang sama, tetapi ditulis menggunakan aturan bahasa pemrograman.

🧩 Pemrograman visual

Perintah disusun melalui blok. Bentuk visual membantu kita melihat urutan, kondisi, pengulangan, dan data.

⌨️ Pemrograman tekstual

Perintah ditulis menggunakan sintaks bahasa tertentu. Contoh yang digunakan pada pembelajaran ini adalah JavaScript.

Pertanyaan pemantik: Jika sebuah blok berkata “jika nilai ≥ 75, tampilkan Lulus”, bagaimana ide itu ditulis dalam kode?

Setelah belajar, kamu mampu…

03 • Konsep Inti

Apa itu translasi konsep?

Translasi berarti menerjemahkan ide/struktur program dari satu bentuk representasi ke bentuk lain tanpa mengubah tujuan logikanya.

🟦 Visual

Blok “set nilai”, “jika…maka”, atau “ulangi”.

↔️ Logika

Aturan dan hubungan antarperintah tetap dipertahankan.

🟩 Tekstual

Logika ditulis dengan sintaks bahasa seperti JavaScript.

Prinsip: yang diterjemahkan adalah logikanya, bukan bentuk bloknya satu per satu.
04 • Fondasi Pemecahan Masalah

Kenali IPO: Input → Process → Output

📥 Input

Data yang masuk ke program.

Contoh: nilai siswa = 82

⚙️ Process

Aturan/perhitungan yang dilakukan.

Contoh: bandingkan nilai dengan 75.

📤 Output

Informasi yang dihasilkan.

Contoh: “Lulus”.

Aktivitas cepat: Untuk program menghitung luas persegi panjang, panjang dan lebar adalah input, p × l adalah proses, dan luas adalah output.
05 • Translasi 1

Urutan perintah → kode berurutan

Konsep visual “lakukan A, lalu B, lalu C” biasanya diterjemahkan menjadi baris kode yang dieksekusi dari atas ke bawah.

Alur logika

1
Simpan nilai panjang

p = 8

2
Simpan nilai lebar

l = 5

3
Hitung luas

luas = p × l

JavaScript

let p = 8;
let l = 5;
let luas = p * l;

console.log(luas);
Output program: 40
06 • Translasi 2

Variabel: “kotak” untuk menyimpan data

Dalam pemrograman visual, kita dapat membayangkan variabel sebagai tempat bernama untuk menyimpan nilai. Dalam JavaScript, salah satu cara membuatnya adalah dengan let.

Konsep

nama → "Ayu"umur → 13nilai → 88

Kode

let nama = "Ayu";
let umur = 13;
let nilai = 88;
Ingat: nama variabel sebaiknya jelas dan menggambarkan data yang disimpan. Nilai dapat berubah selama program berjalan.
07 • Translasi 3

Kondisi “jika…maka” → if

Kondisi digunakan saat program harus memilih tindakan berdasarkan suatu keadaan.

Logika visual

Jika nilai ≥ 75 → tampilkan “Lulus”.
Jika tidak → tampilkan “Belum Lulus”.

JavaScript

if (nilai >= 75) {
  console.log("Lulus");
} else {
  console.log("Belum Lulus");
}
Simbol penting: >= berarti “lebih besar atau sama dengan”. Jangan tertukar dengan = yang digunakan untuk memberi nilai pada variabel.
08 • Aktivitas Interaktif

Coba aturan kelulusan

Masukkan nilai. Program di bawah menerapkan logika nilai ≥ 75.

09 • Translasi 4

Pengulangan → for

Jika suatu tindakan dilakukan berkali-kali, kita tidak perlu menulis perintah yang sama berulang-ulang. Konsep pengulangan dapat diterjemahkan ke struktur for.

Ide algoritma

1
Mulai dari 1.
2
Ulangi selama angka ≤ 5.
3
Tampilkan angka.

Kode

for (let i = 1; i <= 5; i++) {
  console.log(i);
}

Hasil: 1, 2, 3, 4, 5

i++ berarti nilai i bertambah 1 setiap pengulangan.

12 • Contoh Terpandu

Program menghitung luas persegi panjang

Masalah

Diketahui panjang dan lebar sebuah persegi panjang. Buat program untuk menghitung luasnya.

Input: panjang, lebar
Proses: luas = panjang × lebar
Output: luas

Pseudocode

Masukkan panjang
Masukkan lebar
luas ← panjang × lebar
Tampilkan luas

Program tekstual

let panjang = 12;
let lebar = 7;
let luas = panjang * lebar;

console.log("Luas = " + luas);
12 × 7 = 84. Variabel panjang dan lebar menjadi input, operasi perkalian menjadi proses, dan luas menjadi output.
13 • Contoh Kondisi

Menentukan bilangan genap atau ganjil

Masalah: tentukan apakah sebuah bilangan termasuk genap atau ganjil.

Logika

Jika sisa pembagian bilangan dengan 2 adalah 0, bilangan itu genap. Jika tidak, ganjil.

Jika n mod 2 = 0
  tampilkan "Genap"
Jika tidak
  tampilkan "Ganjil"

JavaScript

let n = 17;

if (n % 2 === 0) {
  console.log("Genap");
} else {
  console.log("Ganjil");
}
Operator % menghasilkan sisa pembagian.
14 • Simulator

Uji sendiri: genap atau ganjil

Hubungkan dengan kode

if (n % 2 === 0) {
  hasil = "Genap";
} else {
  hasil = "Ganjil";
}
15 • Debugging

Program tidak selalu benar pada percobaan pertama

Debugging adalah proses menemukan dan memperbaiki kesalahan pada program.

🔤 Sintaks

Aturan penulisan kode salah, misalnya tanda kurung tidak lengkap.

🧠 Logika

Kode berjalan tetapi hasilnya tidak sesuai tujuan.

📊 Data

Input tidak sesuai kebutuhan, misalnya pembagian dengan 0.

Kebiasaan baik: uji program dengan beberapa kasus, termasuk nilai kecil, nilai batas, dan kondisi yang berbeda.

19 • Tantangan

Rancang solusi mini

Bayangkan kamu membuat program yang menerima tiga nilai, menghitung rata-rata, lalu menentukan apakah siswa lulus.

Susun IPO

Input: nilai1, nilai2, nilai3
Proses: rata-rata = (nilai1 + nilai2 + nilai3) / 3
Output: rata-rata dan status

Pikirkan struktur

Variabel untuk menyimpan nilai.

Operasi matematika untuk rata-rata.

if...else untuk menentukan status.

let n1 = 80;
let n2 = 75;
let n3 = 85;

let rata = (n1 + n2 + n3) / 3;

if (rata >= 75) {
  console.log("Lulus");
} else {
  console.log("Belum Lulus");
}

Rata-rata = 80, sehingga statusnya Lulus.
