01 • VARIABEL

Variabel: “kotak” bernama untuk data

Variabel adalah nama yang digunakan program untuk merujuk pada sebuah nilai. Nilai tersebut dapat digunakan dalam proses dan, pada banyak bahasa pemrograman, dapat berubah.

Analogi sederhana

Contoh tekstual

let nama = "Alya";
let umur = 13;
let tinggi = 150.5;

Dalam contoh JavaScript, nama, umur, dan tinggi adalah variabel.

AKTIVITAS

Nilai yang disimpan adalah…

Nama variabelnya adalah…

02 • TIPE DATA

Data memiliki jenis

Tipe data membantu kita memahami bentuk nilai yang digunakan program. Dalam contoh sederhana berbasis JavaScript, beberapa tipe yang penting adalah:

STRING

Teks

let nama = "Bima";

String berisi karakter/teks dan biasanya ditulis di antara tanda kutip.

NUMBER

Bilangan

let nilai = 87;
let berat = 42.5;

Number digunakan untuk bilangan, baik bulat maupun desimal.

BOOLEAN

Benar / salah

let lulus = true;

Boolean hanya memiliki dua keadaan: true atau false.

ARRAY

Kumpulan nilai

let nilai = [80, 75, 90];

Array menyimpan beberapa nilai dalam satu struktur. Untuk pembelajaran dasar, kenali sebagai kumpulan data.

AKTIVITAS TIPE DATA

Tebak tipe datanya

Pilih tipe data yang paling tepat untuk setiap nilai.

03 • OPERATOR

Operator mengolah nilai

Operator memungkinkan program melakukan perhitungan, membandingkan nilai, atau menggabungkan kondisi.

ARITMETIKA

Hitung

+   -   *   /   %

Penjumlahan, pengurangan, perkalian, pembagian, dan sisa bagi.

PERBANDINGAN

Bandingkan

>   <   >=   <=   ===

Menghasilkan nilai boolean berdasarkan hubungan dua nilai.

LOGIKA

Gabungkan kondisi

&&   ||   !

Digunakan untuk AND, OR, dan NOT pada kondisi boolean.

⚠️ Ingat: tanda = pada JavaScript digunakan untuk memberi nilai/assignment, sedangkan === digunakan untuk membandingkan kesamaan nilai dan tipe.
VISUALISASI OPERATOR

Geser nilai, lihat hasilnya

Ekspresi
12 + 5
17
hasil operasi
LANGKAH BERPIKIR

Dari soal ke ekspresi program

Contoh: “Rani memiliki 8 pensil, kemudian membeli 5 pensil lagi. Berapa pensil Rani sekarang?”

04 • INPUT

Input: program menerima data

Input adalah data yang masuk ke program. Pada aplikasi, input dapat berasal dari keyboard, formulir, tombol, sensor, berkas, atau sumber lainnya.

Contoh pemrograman visual

tanya
“Siapa namamu?”
→
simpan
jawaban

Blok “ask and wait” pada lingkungan visual memiliki gagasan yang sama dengan membaca masukan pengguna pada kode tekstual.

Contoh JavaScript di halaman ini

const nama = prompt("Nama kamu?");
console.log(nama);
Untuk web modern, input formulir HTML sering lebih nyaman daripada prompt(). Konsepnya tetap sama: ambil data → simpan → proses.

05 • OUTPUT

Output: program menyampaikan hasil

Output adalah informasi yang dikeluarkan program. Output dapat berupa teks, angka, gambar, suara, tabel, grafik, atau perubahan tampilan.

TEKS

Pesan

console.log("Halo!");
HASIL

Perhitungan

let luas = 10 * 5;

Nilai variabel luas dapat ditampilkan.

TAMPILAN

Antarmuka

element.textContent = "Selesai";
TRANSLASI VISUAL → TEKSTUAL

Blok program dapat diterjemahkan

Yang diterjemahkan bukan bentuk bloknya secara harfiah, melainkan makna instruksi.

Visual

🟦 set panjang to 8
↓
🟦 set lebar to 5
↓
🟩 set luas to panjang × lebar
↓
🟨 say luas

Tekstual

let panjang = 8;
let lebar = 5;
let luas = panjang * lebar;
console.log(luas);

Urutan maknanya sama: buat data → hitung → tampilkan.

AKTIVITAS TRANSLASI

Susun urutan program

Klik kartu dalam urutan yang benar untuk program: meminta panjang dan lebar, menghitung luas, lalu menampilkan luas.

CONTOH 1 • MUDAH

Menghitung jumlah benda

Sebuah kelas memiliki 18 buku Matematika dan menerima 7 buku tambahan. Buat langkah program untuk menentukan jumlah seluruh buku.

Petunjuk: tentukan dua data awal → pilih operator yang sesuai → simpan hasil → tampilkan hasil.
let awal = 18;
let tambahan = 7;
let total = awal + tambahan;
console.log(total);

Jawaban: 25 buku. Operator + dipilih karena jumlah bertambah.

CONTOH 2 • SEDANG

Input nilai dan menghitung rata-rata

Program menerima tiga nilai: 80, 75, dan 85. Hitung rata-ratanya dan tampilkan hasil.

let n1 = 80;
let n2 = 75;
let n3 = 85;

let rata = (n1 + n2 + n3) / 3;
console.log(rata);
Langkah: jumlahkan 80 + 75 + 85 = 240. Karena ada 3 nilai, bagi 240 dengan 3. Jadi rata-rata = 80.
CONTOH 3 • MENANTANG

Belanja: input → proses → output

Harga sebuah buku Rp20.000. Seseorang membeli 3 buku. Program harus menghitung total harga dan menampilkan hasilnya.

Analisis

1
Input/data

harga = 20000 dan jumlah = 3

2
Proses

total = harga × jumlah

3
Output

tampilkan total

Kode

let harga = 20000;
let jumlah = 3;
let total = harga * jumlah;
console.log(total);
Hasil: Rp60.000. Program tidak “menebak”; hasil berasal dari operasi pada data.
ANALISIS KODE

Apa yang terjadi pada program ini?

let alas = 12;
let tinggi = 7;
let luas = alas * tinggi / 2;
console.log("Luas =", luas);
VARIABEL

alas, tinggi, luas

OPERATOR

× dan ÷

OUTPUT

teks “Luas =” dan nilai luas

Luas = 12 × 7 ÷ 2 = 42. Jadi output program menampilkan “Luas = 42”.

KESALAHAN UMUM

Debugging: temukan kesalahannya

KESALAHAN 1
let nama = Alya;
Jika Alya dimaksudkan sebagai teks, tulis "Alya" dengan tanda kutip.
KESALAHAN 2
let luas = panjang + lebar;
Jika menghitung luas persegi panjang, operasi yang benar adalah panjang * lebar, bukan penjumlahan.
KESALAHAN 3
let umur = "13";
Tidak selalu. Itu adalah string. Jika umur akan digunakan sebagai bilangan dalam perhitungan, perlu dikonversi menjadi number.
KESALAHAN 4
console.log(total);
let total = 25;
Deklarasi dengan let sebaiknya dilakukan sebelum variabel digunakan.
