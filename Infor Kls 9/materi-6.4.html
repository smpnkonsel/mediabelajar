Percabangan dalam Pemrograman

Menerjemahkan percabangan dari pemrograman visual ke bentuk sintaks tekstual — dari blok kondisi menjadi instruksi yang dapat ditulis dengan kode.

Pemrograman VisualSintaks Tekstualif / else
Gambaran sederhana
jika nilai >= 75
    → tampilkan "Lulus"
jika tidak
    → tampilkan "Belum lulus"

Intinya: program memilih tindakan berdasarkan kondisi.

03 • KONSEP INTI

Apa itu percabangan?

Percabangan adalah struktur program yang memungkinkan komputer memilih tindakan berdasarkan apakah suatu kondisi bernilai benar atau salah.

🔎

Kondisi

Pernyataan yang diperiksa, misalnya nilai >= 75.

⚖️

Keputusan

Hasil pemeriksaan berupa benar (true) atau salah (false).

🚀

Tindakan

Instruksi yang dijalankan sesuai hasil kondisi.

Data / keadaan masuk
↓
Periksa kondisi
↙      ↘
TRUE
Tindakan A
FALSE
Tindakan B
04 • TRANSLASI

Logikanya sama, bentuknya berbeda

Dalam pemrograman visual, kondisi biasanya ditunjukkan melalui blok. Dalam pemrograman tekstual, kondisi ditulis menggunakan sintaks bahasa pemrograman.

Pemrograman visual — gambaran blok
jika nilai ≥ 75
↓
katakan “Lulus”

Blok kondisi menentukan apakah blok tindakan dijalankan.

Pemrograman tekstual — JavaScript
script.jsif
if (nilai >= 75) { console.log("Lulus"); }

Kurung () berisi kondisi, sedangkan { } membungkus tindakan.

05 • KONDISI

Mengenal operator perbandingan

Operator membantu program membandingkan nilai untuk menghasilkan true atau false.

OperatorMaknaContoh
>lebih besar dariumur > 12
<lebih kecil darinilai < 75
>=lebih besar atau sama dengannilai >= 75
<=lebih kecil atau sama dengannilai <= 100
===sama persisstatus === "hadir"
!==tidak samastatus !== "hadir"
⚠️ Dalam JavaScript, untuk membandingkan nilai secara ketat gunakan ===. Untuk pembelajaran dasar, biasakan menggunakan === daripada ==.
06 • STRUKTUR DASAR

Percabangan satu kondisi: if

Gunakan if ketika tindakan hanya diperlukan jika kondisi benar.

Visualisasi logika

Apakah nilai ≥ 75?
↓
TRUE → tampilkan “Lulus”
FALSE → tidak melakukan tindakan tersebut

Sintaks tekstual

if (nilai >= 75) { console.log("Lulus"); }
Jika nilai memenuhi kondisi, blok di dalam kurung kurawal dijalankan. Jika tidak, program melewati blok tersebut.
07 • DUA CABANG

if ... else

Jika program harus memilih salah satu dari dua tindakan, gunakan if ... else.

nilai ≥ 75?
TRUE
Lulus
FALSE
Belum lulus
Terjemahan tekstualJavaScript
if (nilai >= 75) { console.log("Lulus"); } else { console.log("Belum lulus"); }
💡 Ingat: else tidak memiliki kondisi sendiri. Ia menangani keadaan ketika kondisi if bernilai false.
08 • BANYAK KONDISI

if ... else if ... else

Jika ada lebih dari dua kemungkinan, beberapa kondisi dapat diperiksa secara berurutan.

if (nilai >= 90) { predikat = "A"; } else if (nilai >= 80) { predikat = "B"; } else if (nilai >= 75) { predikat = "C"; } else { predikat = "D"; }

1. Periksa A

Jika nilai ≥ 90, berhenti pada cabang A.

2. Jika tidak, periksa B/C

Program melanjutkan pemeriksaan berikutnya.

3. Jika semua gagal

else menjadi pilihan terakhir.

09 • PROSEDUR

Langkah menerjemahkan blok menjadi kode

1
Temukan kondisi.
Misalnya blok bertuliskan “jika nilai ≥ 75”.
2
Tentukan operator.
“≥” diterjemahkan menjadi >= dalam JavaScript.
3
Tulis if.
Kondisi diletakkan di dalam tanda kurung ( ).
4
Masukkan tindakan.
Perintah yang ada di dalam cabang visual ditulis di dalam { }.
5
Terjemahkan cabang alternatif.
Blok “jika tidak” menjadi else, sedangkan kondisi alternatif menjadi else if.
6
Uji beberapa nilai.
Coba nilai yang masuk ke cabang benar, salah, dan batas kondisi.
10 • CONTOH TERBIMBING

Contoh 1 — Menentukan kelulusan

Seorang siswa memperoleh nilai 78. Batas lulus adalah 75. Bagaimana logika percabangannya?
Bandingkan 78 dengan 75 menggunakan operator >=.
1) Kondisi: nilai >= 75.
2) Karena 78 ≥ 75, kondisi bernilai true.
3) Jalankan tindakan untuk cabang true.
const nilai = 78; if (nilai >= 75) { console.log("Lulus"); } else { console.log("Belum lulus"); }
Hasil: Lulus
11 • CONTOH KONTEKSTUAL

Contoh 2 — Menentukan status kehadiran

Percabangan juga dapat digunakan untuk situasi sehari-hari di sekolah.

Logika

Jika siswa datang dan sudah melakukan kepulangan, statusnya Hadir. Jika belum pulang, statusnya Belum Pulang. Jika tidak datang, statusnya Alpa.

Sudah datang?
↓
Sudah pulang?

Salah satu bentuk tekstual

if (!datang) { status = "Alpa"; } else if (pulang) { status = "Hadir"; } else { status = "Belum Pulang"; }

Urutan kondisi penting karena program memeriksa dari atas ke bawah.

17 • POLA PENTING

Kenali pola blok → sintaks

“Jika”

Blok jika kondisi → if (kondisi) { ... }

“Jika tidak”

Blok alternatif tanpa kondisi → else { ... }

“Jika kondisi lain”

Cabang dengan kondisi baru → else if (kondisi) { ... }

Checklist sebelum menjalankan program

✓ Apakah kondisinya benar?
✓ Apakah operator perbandingannya sesuai?
✓ Apakah tindakan ditempatkan di cabang yang tepat?
✓ Apakah urutan else if sudah tepat?
✓ Sudahkah mencoba nilai batas, misalnya tepat 75 atau 90?
