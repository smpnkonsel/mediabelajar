Konsep Dasar

Dua Kategori Utama Perulangan

Secara umum, baik dalam pemrograman visual maupun tekstual, perulangan dibagi menjadi dua kategori:

🔢

1. Counted Loop (Terhitung)

Digunakan ketika kita sudah mengetahui pasti berapa kali iterasi / pengulangan harus dilakukan.

Visual: Block repeat (N) Tekstual: for i in range(N):
🎯

2. Uncounted Loop (Bersyarat)

Digunakan ketika jumlah perulangan belum pasti, tergantung pada terpenuhinya suatu kondisi/syarat tertentu.

Visual: Block repeat until [kondisi] Tekstual: while not [kondisi]:
Translasi #1

Counted Loop: Repeat (N) ➔ For Loop

Mari kita bandingkan bagaimana perulangan terhitung disajikan pada kedua dunia pemrograman:

Pemrograman Visual (Scratch)

repeat 4
move (10) steps
turn ↻ (90) degrees

Badan instruksi dimasukkan ke **dalam cangkang** blok repeat.

Pemrograman Tekstual (Python)

for i in range(4): move(10) # Spasi Indentasi turn(90) # Spasi Indentasi

Cangkang blok digantikan oleh **tanda titik dua (:)** dan **Indentasi (4 spasi)**.

🔍 Rahasia Translasi:

Fungsi range(4) di Python akan menghasilkan urutan angka 0, 1, 2, 3 (berjumlah 4 kali putaran).

Kunci Penting

Indentasi: Pengganti "Cangkang" Blok

Dalam blok visual, Anda tahu suatu perintah berada di dalam perulangan karena ditaruh **di dalam cangkang**. Bagaimana dengan tekstual?

⚠️ CONTOH BENAR
for i in range(3): print("Langkah") # Dalam loop print(i) # Dalam loop print("Selesai") # Luar loop
❌ KESALAHAN UMUM (IndentationError)
for i in range(3): print("Langkah") # ERROR! Tidak ada indentasi
📌 Mengapa Indentasi Sangat Krusial di Python? +
Python tidak menggunakan tanda kurung kurawal `{}` atau cangkang visual untuk menandai batas blok program. Python sepenuhnya mengandalkan **spasi indentasi** (biasanya 4 spasi atau 1 Tab). Semua baris yang menjorok ke dalam dianggap sebagai isi badan dari perulangan tersebut.
Translasi #2

Uncounted Loop: Repeat Until ➔ While Loop

Perulangan bersyarat berjalan selama suatu kondisi belum/masih terpenuhi.

Block Visual (Scratch)

repeat until touching [Dinding]?
move (5) steps

Ulangi **SAMPAI** menyentuh dinding.

Python (While Loop)

while not touching_wall(): move(5)

Jalan **SELAMA TIDAK** menyentuh dinding.

⚠️ Perbedaan Logika Penting:

Block repeat until berhenti ketika kondisi bernilai **TRUE**. Sedangkan Python while berjalan selama kondisi bernilai **TRUE** (berhenti saat FALSE). Maka dari itu, kita sering menggunakan kata kunci not untuk menyesuaikan logikanya!

Tantangan Translasi Mandiri

Cobalah menerjemahkan kasus skenario berikut sebelum membuka kunci jawabannya!

📜 Soal Skenario:

Buatlah struktur perulangan Python yang akan mencetak kata "Informatika" sebanyak 5 kali, dan setelah perulangan selesai, cetak kata "Selesai!" sebanyak 1 kali.

for i in range(5): print("Informatika") # Menggunakan Indentasi (Didalam loop) print("Selesai!") # Tanpa Indentasi (Di luar loop)

💡 Pembahasan: Baris print("Selesai!") tidak diberi indentasi agar hanya dieksekusi **satu kali saja** tepat setelah perulangan for rampung seluruhnya.
